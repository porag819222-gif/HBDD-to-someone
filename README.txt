GitHub + Cloudflare Pages e live korar niyom

1. GitHub e notun repo banao (jemon: queen-story).
2. Ei folder er sob kichu (index.html, images/, audio/, thumbnail.jpg) repo te upload koro.
   index.html ta repo r ekdom root e thakte hobe.
3. Cloudflare Dashboard > Workers & Pages > Create > Pages > Connect to Git, repo ta select koro.
4. Build command: khali rakho. Build output directory: / (ba khali).
5. Save and Deploy. Kichu khon por tomar link pabe: https://nam.pages.dev
6. Link share e thumbnail dekhate chaile index.html e og:image line e pura link bosao:
   https://nam.pages.dev/thumbnail.jpg
